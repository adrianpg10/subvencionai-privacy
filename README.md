# Política de Privacidad — SubvenciónAI

**Última actualización:** junio 2026

## Datos que recopilamos
SubvenciónAI no recopila ni almacena datos personales de los usuarios.

## Datos que procesamos
El texto de las páginas web que el usuario decide analizar se envía a nuestra API 
para su procesamiento. Este texto no se almacena en ningún servidor.

## Datos locales
El perfil del usuario (tipo de empresa, sector, comunidad autónoma) se guarda 
únicamente en el navegador del usuario mediante chrome.storage.local. 
Estos datos nunca salen del dispositivo del usuario.
